radhdl_lattice_tdp_ram

Documentation version: 0.2.2 / Subpackage: primitive_ram / Source package: radprimitive

ECP5 true dual-port RAM wrapper backed by explicit DP16KD blocks. This first implementation covers one 18x1024 DP16KD shape; wider/deeper banking should be added here rather than inferred in consumer cores.

Testbenches: 1

Use Cases

  • Reusable RadHDL building block for graph-generated FPGA systems.
