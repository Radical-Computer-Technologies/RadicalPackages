radhdl_fifo_bram_async

Documentation version: 0.2.2 / Subpackage: primitive_fifo / Source package: radprimitive

RAD separate-clock FIFO built from explicit vendor RAM wrappers and Gray pointer CDC. This is the ECP5 path and the generic fallback for families without vendor FIFO IP.

Register interfacesTestbenches: 1
