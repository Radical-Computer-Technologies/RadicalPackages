radhdl_lattice_fifo8kb

Documentation version: 0.2.2 / Subpackage: primitive_fifo / Source package: radprimitive

Lattice MachXO2/MachXO3 FIFO8KB primitive wrapper. This is intentionally a primitive wrapper, not a RAM-inferred FIFO.
