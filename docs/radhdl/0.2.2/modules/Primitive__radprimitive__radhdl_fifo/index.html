radhdl_fifo

Documentation version: 0.2.2 / Subpackage: primitive_fifo / Source package: radprimitive

Public vendor-neutral FIFO primitive. Synchronous and asynchronous modes route to explicit vendor FIFO IP or hard FIFO macros. This wrapper deliberately avoids inferred FIFO storage.

Register interfacesTestbenches: 2

Use Cases
