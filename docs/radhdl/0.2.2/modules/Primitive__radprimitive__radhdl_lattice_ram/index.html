radhdl_lattice_ram

Documentation version: 0.2.2 / Subpackage: primitive_ram / Source package: radprimitive

Public Lattice RAM wrapper. Internally delegates to the explicit DP16KD implementation; consumer cores should instantiate this name.

Use Cases

  • Reusable RadHDL building block for graph-generated FPGA systems.
