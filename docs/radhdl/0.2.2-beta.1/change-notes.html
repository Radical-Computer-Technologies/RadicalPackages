Version Change Notes

Documentation version: 0.2.2-beta.1

This beta documentation snapshot reflects the Crimson primitive portability and FPiGA Audio integration work.

Highlights

  • Expanded RadPrimitive coverage for vendor-neutral RAM, FIFO, CDC, and DSP wrapper entry points.
  • Added explicit Gowin and Lattice primitive-backed paths where available, while keeping generic models available for simulation and unsupported families.
  • Added searchable datasheet organization for primitive RAM, FIFO, CDC, DSP, RADIF interface, RADDSP, and RadDebug/RadILA modules.
  • Added contribution guidance for primitive policy, simulation expectations, and HDL style.
  • Packaged the FPiGA Audio Hat shared-math example with top-level I2C/I2S simulation infrastructure.
  • Refreshed RadBuild integration so the packaged RadHDL catalog can be consumed by beta RadBuild projects.
